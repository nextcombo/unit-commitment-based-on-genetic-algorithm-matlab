# Unit Commitment Based on Genetic Algorithm (Matlab)

This application seeks the optimal load (unit commitment) for power plants, based on optimization methods: genetic algorithms and dynamic programming.  
To run this application, it is necessary to know the cost function of generators in the power station.  
This application is applicable to power stations containing 10 or fewer generators.
